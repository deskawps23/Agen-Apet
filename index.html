Struktur database Firebase yang saya sarankan

Karena Firestore bersifat dokumen, struktur paling aman adalah memisahkan data master wilayah, data stokis, data kurir, dan transaksi distribusi. Ini tetap sederhana, hemat query, dan gampang dipakai di dashboard.

Langkah setup yang harus Anda lakukan

Saya buat singkat dan praktis supaya Anda bisa langsung jalan. Setelah langkah ini, website GitHub Pages Anda bisa mulai membaca dan menulis data ke Firebase.

Tahap Implementasi

Buka Firebase Console

Masuk ke project Firebase Anda, lalu aktifkan Firestore Database dalam mode test terlebih dahulu untuk pengembangan awal.

Tambahkan Web App

Di Project Settings, buat atau pakai Web App lalu salin object firebaseConfig.

Buat collection utama

Buat collection: kecamatan, desa, stokis, kurir, dan distribusi.

Tempelkan config ke website

Masukkan config Firebase ke file HTML aplikasi Anda, lalu import SDK Firebase versi web modular.

Deploy ke GitHub Pages

Commit file ke repository Agen-Apet-Pandeglang-. Karena GitHub Pages Anda sudah aktif, perubahan akan langsung ter-publish.

Set rules dasar

Setelah testing berhasil, jangan biarkan mode test terlalu lama. Atur rules agar hanya user tertentu yang bisa mengubah data.

Kode dasar Firebase untuk aplikasi Anda

Di bawah ini adalah starter code yang bisa langsung Anda tempel ke aplikasi HTML Anda. Tinggal ganti isi firebaseConfig dengan milik project Firebase Anda.

Starter Code
firebase setup 
<script type="module">
  import { initializeApp } from "https://www.gstatic.com/firebasejs/10.12.5/firebase-app.js";
  import {
    getFirestore,
    collection,
    addDoc,
    getDocs,
    serverTimestamp
  } from "https://www.gstatic.com/firebasejs/10.12.5/firebase-firestore.js";

  const firebaseConfig = {
    apiKey: "ISI_API_KEY_ANDA",
    authDomain: "PROJECT-ID.firebaseapp.com",
    projectId: "PROJECT-ID",
    storageBucket: "PROJECT-ID.firebasestorage.app",
    messagingSenderId: "ISI_SENDER_ID",
    appId: "ISI_APP_ID"
  };

  const app = initializeApp(firebaseConfig);
  const db = getFirestore(app);

  async function tambahStokis() {
    try {
      await addDoc(collection(db, "stokis"), {
        kodeStokis: "STK-001",
        namaStokis: "Stokis Labuan 01",
        kecamatanId: "labuan",
        kecamatanNama: "Labuan",
        desaId: "labuan-kel",
        desaNama: "Labuan",
        penanggungJawab: "Asep",
        noHp: "081234567890",
        alamat: "Jl. Raya Labuan",
        status: "Aktif",
        totalStok: 320,
        createdAt: serverTimestamp()
      });
      alert("Data stokis berhasil ditambahkan");
    } catch (error) {
      console.error("Gagal tambah stokis:", error);
    }
  }

  async function ambilStokis() {
    const querySnapshot = await getDocs(collection(db, "stokis"));
    const data = [];
    querySnapshot.forEach((doc) => {
      data.push({ id: doc.id, ...doc.data() });
    });
    console.log("Data stokis:", data);
  }

  window.tambahStokis = tambahStokis;
  window.ambilStokis = ambilStokis;
</script>
